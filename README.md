# Frontend de productos

Frontend HTML, CSS y JavaScript del practico de Full Stack.

Necesita la API de productos funcionando en http://localhost:3000
y su base de datos configurada.

Abrir esta carpeta en VS Code y usar Open with Live Server
sobre index.html. Debe abrir en http://127.0.0.1:5501.

Alternativa desde terminal: php -S 127.0.0.1:5501
